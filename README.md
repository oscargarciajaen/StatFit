# StatFit

StatFit es una aplicación web para crear y organizar rutinas de entrenamiento de gimnasio, calistenia o casa.

También permite registrar el peso corporal, calcular las calorías diarias necesarias y hacer un seguimiento de las calorías y los nutrientes consumidos cada día.
