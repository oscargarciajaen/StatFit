# Brief del proyecto

## Problema que resuelve:

Este proyecto resuelve varios problemas del mundo del deporte, entre ellos se encuentran:

- El conteo de series y repeticiones de los ejercicios que estás haciendo en el gimnasio.

- El seguimiento de los pesos por series para tener un registro del nivel de intensidad con la que haces los ejercicios, para posteriormente tener unas estadísticas de tu avance.

- El conteo de calorías diarias que necesitas y un desglose de porcentaje por tipo de nutrientes.

- El calcular cuantas calorias necesita tu cuerpo.

- El obtener las calórias de tus alimentos mediante una foto.

¿Cómo afrontamos estos problemas?

- La aplicación va a tener una interfaz intuitiva y sencilla para poder ingresar los pesos independientemente de que el usuario haga dropsets o series convencionales.

- La aplicación va a registrar en una base de datos los registros proporcionados por el usuario para mantener los pesos, series y ejercicios realizados cada sesión de entrenamiento.

- La aplicación gracias a la herramienta de inteligencia artificial generará un conteo de calorías y de nutrientes para hacerte un desglose visual en el que te puedas basar para llegar a tu objetivo.

- La aplicación tendrá una herramienta de cálculo que te ayudara a obtener el número diario de calorías que necesitas.

La aplicación está pensada para tulizarse desde el teléfono ya que parte de su uso esta pensado para la utlización de la misma en el gimnasio, aunque puedes utilizarla desde el ordenador.

### ¿Cómo se si mi proyecto funciona?

Realizare pruebas y personas externas probaran la aplicación para comprobar que satisface las necesidades y cumple con lo prometido.
